# LiveFire handoff contracts, v1.0 (frozen at G1, Oct 26 2026)

Source of truth: `src/drill-runner/livefire/contracts.py`. JSON schemas: `schemas/`, generated by
`python scripts/export_schemas.py`; a test fails if they are stale. WS4 approves every change, bumps
`CONTRACT_VERSION`, and tells every affected workstream the same day.

| Model | Written by | Guarantees |
| --- | --- | --- |
| PlannerOutput | Planner, both passes | exactly one of RecoveryOptions or RemediationBrief |
| RecoveryOptions | Planner pass 1 | at most 2 options, each tied to one of two known actions; recommendation on offer; evidence cited |
| RemediationBrief | Planner pass 2 | blueprint 5.2's ten fields; at least 2 evidence refs; paths inside the Engineer allowlist |
| ChangeReport | Engineer | branch candidate/<drill_id>-<attempt>; at most 3 changed paths, none protected; changes mapped to evidence and criteria |
| ApprovalRequest / ApprovalDecision | workflow / Control Center | request IDs apr-N; purpose recovery, deploy or acceptance |
| AutonomyPolicy / Budgets | operator | mode, pre-authorized actions (never the broad action), minimum confidence, budgets, expiry |
| Verdict / VerdictInputs | workflow only | the nine terminal states; the six verdict inputs |
| Event / RefereeResult / OpsResult | everyone / WS2 | events.jsonl line format; referee result; Ops replies |
| EvidencePackage | workflow only | package.json, sealed with the SHA-256 of the event log |

Strict schemas the agents answer in: `schemas/PlannerOutput.strict.json`, `schemas/ChangeReport.strict.json`.
